# 🚀 Modern Product Launch – Area

Este projeto é uma **landing page responsiva** desenvolvida como parte dos meus **estudos em Front-End**, marcando o **primeiro projeto que construí de forma realmente séria e estruturada**.

Antes dele, eu já havia feito alguns projetos menores, mas eram focados apenas em **treinar conceitos básicos**.
Neste projeto, o objetivo foi **simular um cenário real**, aplicando boas práticas de desenvolvimento Front-End e versionamento.

Durante o desenvolvimento, **passei a adotar boas práticas de Git**, como commits mais frequentes e descritivos, entendendo melhor o fluxo de trabalho com versionamento ao longo do processo.

---

## 🧠 Sobre o projeto

A landing page apresenta o produto fictício **Area**, uma plataforma que **gerencia, visualiza e analisa dados de negócios**, ajudando empresas a obter insights claros sobre sua operação.

O foco do projeto foi:

* Estrutura semântica
* Layout moderno
* Responsividade
* Acessibilidade básica
* Código organizado e escalável

## 🛠️ Tecnologias utilizadas

* **HTML5**

  * Estrutura semântica
  * Uso de `header`, `nav`, `main`, `section`, `footer`, etc.

* **CSS3**

  * Flexbox
  * Layout responsivo
  * Organização modular de arquivos CSS
  * Boas práticas de espaçamento e alinhamento

* **JavaScript**

  * Interações básicas (menu mobile e comportamentos simples)

* **Git & GitHub**

  * Versionamento do projeto
  * Adoção progressiva de boas práticas de commits
  * Organização do histórico de mudanças

## ♿ Acessibilidade

Foram aplicadas boas práticas iniciais de acessibilidade, como:

* Uso de HTML semântico
* `aria-label`, `aria-hidden` e `role` quando necessário
* Textos alternativos (`alt`) em imagens relevantes
* Estrutura clara de navegação
